# V3：对象遮挡 SSL 与支持编译 SER-PaV

当前仅维护 V3：`isolated-target-structured-feedback-shine-rl-v3`。
2,275,350 个参数可训练，958,345 个 anchor 参数冻结。
旧版文档与诊断存放于 [archive](archive/README.md)，运行记录和源码快照保留。

## 信息边界

训练读取六个已知格。预测器只看到第一行三格和第二行前两格，第六格
仅提供不可训练的教师目标和同构型负例。答案候选、答案索引和 XML 均不
进入适配。教师历史预训练使用过未标注候选负例，因此整个训练历史不是
候选无关。训练的 BatchNorm 冻结，持出目标不能改变可见格表示。

推断时，第一行和第二行分别作为完整支持行，第三行前两格为 query。
八个候选仅作为固定教师目标参与最终误差计算，不改变支持参数、查询
表示或误差反馈。两个支持行的分数求和，再对两个组件视图平均。

## SSL：学习对象表示

逐格独立外轮廓提议最多十个区域。80px 像素经过8px patch投影、96维六头
attention的三个层级；各层用区域加权均值、masked cross-attention和FFN
生成对象 token，并保留场景 token。它们是三个网络深度，不代表三个物体尺度。

对象包围框独立放到白色画布上，由冻结 CNN 编码后池化，产生固定外观
目标。框外像素无法改变该对象目标；位置、尺度和框内重叠物体仍可能影响
表示。轮廓是图像先验，不是已经验证的语义对象分割。

两个任务共享这个编码器：

1. 第一行完整 + 第二行前两格，预测已知第六格。每个目标最多七个同布局、
   同组件的训练已知格负例，排除完全重复的图像。
2. 在前五格随机遮一个完整 bbox，保留其余四格。删除被遮对象的干净区域
   mask和几何/颜色 metadata，只给预测 query 中心与所在格身份，预测
   固定教师外观。第六格不能进入这个辅助任务。

损失固定为已知格排序 CE + 0.1 补全能量 + 0.1 对象遮挡误差。
没有双向行任务或坍塌正则。

## SER-PaV：支持行生成推理参数

三层支持对象表示通过 cross-attention 生成每层48个记忆 token；四层
attention交替处理网络深度轴和记忆token轴。零初始化的深度/token身份
在记忆提取后加入；编译器采用post-norm、GELU、dropout0。

记忆以SHINE `rl`排列生成三阶段P/G/V因子：A按width×rank排列，再转置
供执行；B按rank×width排列。秩为8、宽度96。FP32向量归一化属于本项目
的数值适配。该排列的梯度检查不能证明实际训练后必然具有秩8。

P修正预测状态，G控制更新，V转换验证状态与误差。每阶段同时预测支持
末格与query末格。支持反馈保留25个局部/池化dense误差token和十个经
transport对齐的外观、几何、存在概率误差token。query读取支持状态作为
key、这些误差作为value，经G/V修正下一阶段。支持重建提供内部误差信号，
本身不证明跨行规则泛化。

各阶段的dense预测和对象集合预测使用同一误差公式，与候选目标比较。
对象集合含空槽，以十步FP32熵正则transport处理排序和数量。

`score = frozen_anchor + 0.2 * tanh(gate) * (conditional_energy - prior_energy)`

两条支持行分别执行；新分支必须实际改变答案并对独立支持交换有响应。
零门控等同anchor不能成为新增机制的效果证据。

| 文件 | 单一职责 |
| --- | --- |
| `data.py` | 视图与独立区域提议 |
| `perception.py` | 像素/对象表示、固定目标和遮挡头 |
| `representations.py` | 可见上下文与固定教师目标的独立数据契约 |

## 2026设计来源

| 论文 | 采用的结构 | 适配边界 |
| --- | --- | --- |
| [Object-centric LeJEPA](https://arxiv.org/abs/2607.02404) §4.1 | 区域加权均值、masked cross-attention、残差聚合 | 未采用SAM/SIGReg，不继承语义表示或下游收益结论 |
| [Causal-JEPA](https://arxiv.org/abs/2602.11389v2) §4 | 整实体遮挡、固定教师目标、masked预测 | 静态RAVEN，不主张因果识别或视频动力学复现 |
| [SHINE](https://arxiv.org/abs/2602.06358) §3.3–3.4及Appendix A.2 | 多层记忆、交替attention、`rl`动态低秩参数 | 不继承LLM任务性能；FP32归一化为本项目适配 |

论文版本和原文hash见 [papers.json](papers.json) 与
[SHINE源码清单](shine_source_manifest.json)。SAMBA仅是调研参考，当前没有Mamba模块。

## 固定实验与现有证据

完整划分为42k训练/14k验证/14k测试；七构型各2k验证和测试题。
适配8轮，Adam lr3e-4、wd1e-5、clip1、batch128、Metal workers2。
验证集的第一个最大值选best，末轮final单列。源代码、config、checkpoint
和RNG封存；源码整理后仍用原始训练快照复核已有实验。

三个适配种子共享一个预先指定anchor。两项同容量、同预算对照分别关闭
对象遮挡权重、令新增支持分支成为静态参数生成器。对照通过源码导出，
不增加生产模型的模式开关。已完成原版16轮续训对照的测试为71.4714%；
它使用未标注候选负例，V3适配不使用，数据使用方式不同。

用户将目标改为至少70%测试准确率。该策略在部分验证结果已经可见、
V3首次测试前单独记录；不是训练前预注册的门槛。best完整验证须≥70%，
并且新增分支和支持干预实际改变答案，才打开主模型测试。对照允许报告
下降。测试不用于选checkpoint、架构、权重或种子。

主种子12345：验证选中的第1轮，测试9979/14000=**71.2786%**；最终第8轮
9750/14000=**69.6429%**。同平台anchor为9975/14000=71.25%，最佳模型
净增加4题；这一个种子不能支持统计显著性或两个独立贡献的收益结论。
两个贡献对照已完成，另两个适配种子仍待完成。

完整七配置、源码及checkpoint封存见 [主种子评估](v3_primary_test.json)
和 [收集器核验](v3_primary_collection.json)。历史CUDA和当前Metal存在小量
预测差异，结果按同平台比较；官方57.1%的原版测试选模协议也不同。
