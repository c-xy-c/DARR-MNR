# 统一能量框架的两个可检查性质

这些结论描述已实现的计算，不能替代性能实验或证明语义规则可识别。

## 1. SSL与PaV使用同一个验证责任

支持行先确定规则权重alpha，所有查询候选共享它。各规则的查询误差为
E_k，边缘化能量为

```math
E=-\tau\log\sum_k\alpha_k\exp(-E_k/\tau).
```

给定支持行，对每个规则误差求导得到

```math
\frac{\partial E}{\partial E_k}=
\frac{\alpha_k\exp(-E_k/\tau)}
 {\sum_j\alpha_j\exp(-E_j/\tau)}=\rho_k.
```

rho是验证当前完成时的规则责任。alpha在候选之间固定，rho可以因当前
完成的误差而变化。这区分了候选无关的验证标准与候选相关的验证结果。
不能把边缘化后的rho误称为固定编译器输出。

CECS对真实已知完成的后验能量和布局匹配的内生负例计算条件InfoNCE，因此
同一个rho决定补全参数的训练责任。证据比PaV的后验项也用它分配验证责任，
并扣除均匀混合兼容度。固定支持权重时，证据比对每个规则误差的导数为
rho_posterior减去rho_uniform。SSL没有直接最小化这个差值，二者共享
可执行算子及后验兼容度，但承担不同的训练和推断目标。
SSL和PaV分别承担目标构造和推断，不是互不相关的两个附加模块。

由于rank-4修正真实执行于查询特征，能量对BA参数的梯度穿过补全函数。
支持信息进入查询的唯一新路径是alpha，查询算子不能直接读取支持特征。
这排除了被首版试验证实存在的直接上下文绕过路径，但仍不保证所有
算子都学到独立语义，或所有题都需要不同规则。

## 2. 对基线排序的确定性扰动界

归一化特征的范数至多为1，每个平方距离至多为4，空间/池化平均能量
仍在[0,4]。alpha非负且和为1，所以边缘化能量也在[0,4]。
这里讨论精确算术，浮点实现的检查加1e-6余量。

直接后验形式的基础分数为S_0(y)，新分数为S(y)=S_0(y)+beta E(y)。设基础选择y_0，
次优候选与它的分数差为m。如果

```math
m>4\beta,
```

基础选择必然保持。证明是任何候选与y_0的新增分数差至少为-4beta，
不足以抵消原来的正间隔。

证据比Delta E是两个[0,4]能量之差，范围为[-4,4]，对应的充分条件为
m>8beta。这仍是保守界。两种形式都可使用更紧的逐题可观测界。
定义新增分数delta(y)=S(y)-S_0(y)，如果

```math
m>\max_y\delta(y)-\min_y\delta(y),
```

基础选择也必然保持。该界只用候选分数，不需要正确答案。验证审计会
计算每题的间隔和扰动范围，检查所有满足条件的题是否真的保持选择。

这不是“准确率不会下降”的定理。间隔很小的题仍可能被改对或改错，
只能用完整测试结果判断是否达到70%。为了避免没有生效的保底方案，
还要同时报告真正改变选择的题数、规则均匀化和交换的影响，以及新
SSL相对同预算目标消融的补全能力。没有这些证据，保留基线准确率也
不足以证明两个贡献成立。

## 3. 支持证据的候选兼容度比

记Z_alpha(y)=sum_k alpha_k exp(-E_k(y)/tau)，Z_uniform(y)取相同算子
的均匀权重。实际执行的证据比为

```math
\Delta E(y)=-\tau\log\frac{Z_\alpha(y)}{Z_{\rm uniform}(y)}.
```

对两个兼容度在同一有限候选集合上分别归一化，得到p_alpha与p_uniform。
负对数概率比乘以tau与Delta E只差候选共享的归一化常数，因此作为原版
分数的增量时得到相同排序。这个关系是能量定义的代数性质，不证明真实
数据来自这些混合模型，也不证明条件校准必然提高准确率。

如果alpha均匀，Delta E逐候选严格为零。因此固定均匀权重的模型和冻结
均匀干预在此形式下都回到基础评分。这是可验证的消融定义。完整模型
还必须实际改变部分选择，不能仅报告回到基础评分后的70.38%。
