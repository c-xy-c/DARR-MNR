# 第三版完整实验结果

## 固定协议

数据为完整RAVEN，42000训练题、14000验证题、14000测试题，每个构型的
验证和测试各2000题。seed12345、batch128、单RTX4090。基础模型来自
已完成20轮实验的验证最佳第17轮。每组新增8轮，每轮329步，末轮路径
为17+8。基础20轮加适配8轮是单个最终方法的训练选择预算，不包括
另外三组对照或两个否决原型的研究成本。

第三版训练只让前五个可观察输入决定全局分图回退。待预测第六格及候选
独立回退。基础全部冻结的完整组和固定组只训练CECS。原目标组训练新
分支的原版候选margin。续训对照只更新原版推理块，CNN和BatchNorm冻结。

检查点先按训练时的直接后验评分、权重0.1选择。验证诊断后加入支持
证据比推断，在两个评分形式与三个正权重0.05、0.1、0.2的六项网格中
选择。没有用新评分重选八轮检查点。完整组选择证据比、权重0.05。
配置、检查点、代码及验证结果先锁定，之后打开完整测试集。

## 两项机制的证据

完整验证集上的已知末格检索，以批内同布局、同组件的其他已知末格为
负例。它不是八候选答题准确率。每题两个组件的检索结果一起参与配对
bootstrap，区间反映该验证集和已固定模型的题目差异，不是种子间方差。

| 方法或干预 | 已知末格检索 | 补全损失 |
| --- | ---: | ---: |
| 完整CECS | 14.16% | 4.3871 |
| 新分支用原版margin训练 | 12.02% | 4.5679 |
| 固定均匀权重训练 | 12.46% | 4.4640 |
| 完整模型的均匀权重干预 | 13.13% | 4.4932 |

CECS相对原目标适配的检索收益为2.14个百分点，95%配对区间[1.81,2.49]。
固定模型的支持均匀化干预降低1.03个百分点，区间[0.77,1.29]。
完整方案在验证候选排序上改变45题，17题改对、17题改错。实际扰动界
保证13044题不变，逐题检查没有违反该界。

交换同布局、同组件的支持权重后，验证准确率为70.15%。完整模型与它的
差为0.02个百分点，区间[-0.06,0.11]。没有足够证据声称支持校准提高
候选答题准确率。机制的已知格补全证据与候选排序局限必须同时报告。

## 资源和复核

完整方案新增161170个参数，基础930624个参数全部冻结。各组八轮训练
与逐轮验证累计壁钟分别为14.46、15.24、16.22、16.59分钟。各组的
训练图像数、可训练参数和执行计算不同，不能称为相同计算量。部分独立
验证诊断与最后一组训练并发，实际壁钟记录已包含这项影响。

四组训练退出码、验证审计及测试评估退出码均为0。完整14000题的基础、
后验分支及证据比验证均核对了原生/缓存计数与验证加载器随机状态。
完整方案的锁定最佳测试也与原生图像评估完全一致。

权重、完整逐轮记录、验证审计、网格、测试锁和完整测试结果位于
[program_ssl/results/support-program-v3](../../program_ssl/results/support-program-v3)。
训练源快照与最终评估源快照分开保留。第二版的目标预处理泄漏记录在
[archive-v2/rejection.json](archive-v2/rejection.json)，未用其测试结果选模。

该实验满足70%门槛，并给出两个机制的计算定义与补全对照证据。它没有
证明语义规则发现、种子稳定性、跨数据集泛化或两项贡献都提高候选准确率。
