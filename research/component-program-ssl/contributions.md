# 两项贡献的统一表述

## 核心研究对象

在已有组件视图与冻结SSPredRNet表征上，学习一组能够实际执行缺格补全的
参数假设。完整支持行确定这些假设的权重，查询候选接受同一组权重的
验证。工作名称为**组件条件的可执行补全与支持证据验证**。

已有70.38%分图版本是基础模型。布局分图不算本次新增贡献，也不等于
学习到对象发现。基础模型的预训练使用过答案候选负例，新增适配阶段
才具有候选不参与训练的边界。

## 贡献一：可执行组件补全自监督，CECS

以第一行三格为支持、第二行前两格为查询，预测第二行真实末格的冻结
CNN特征。支持信息只能通过六个补全算子的权重进入新预测分支，算子
本身不能直接读取支持行。每个算子保留空间特征，并带有可学习仿射系数
及rank-4修正。

训练同时降低真实末格的条件能量，区分其他训练题的已知末格。负例限定
相同公开布局与组件索引，排除与真实末格逐像素相同的图像。目标及候选
不能改变前五格的预处理。该任务不用答案索引、XML、答案候选、双向行
交换任务或坍塌正则。

贡献范围是**已知上下文内的条件补全信号和执行瓶颈**。对照检验补全
检索与条件InfoNCE，不将基础CNN已有的感知能力归因于这八轮适配。

## 贡献二：支持证据比预测与验证，SER-PaV

完整支持行先让每个算子预测其第三格，以实际预测误差校准假设权重。
测试时，两条完整支持行通过归一化几何平均形成共享权重。每个候选的
兼容度对假设进行边缘化，避免先把不同预测平均成一个特征。

验证增量采用支持条件混合与均匀混合的能量差。它相当于负对数兼容度比，
用于扣除没有支持证据也能得到的候选外观兼容度。均匀支持权重下，新项
严格为零。条件权重有效时，新项可以改变原版的候选排序。

贡献范围是**候选之间固定的支持证据校准与增量验证准则**。它没有重新
设计或训练基础三层PaV。支持交换和均匀化可测即时依赖，不能证明发现了
可解释的RAVEN语义规则。

## 同一理论架构

```math
Z_\alpha(y)=\sum_k\alpha_k\exp[-E_k(y)/\tau],\qquad
E_\alpha(y)=-\tau\log Z_\alpha(y).
```

CECS学习真实补全相对训练负例的条件兼容度，SER-PaV用同一个后验兼容度
相对均匀兼容度的证据比修正基础排序。

```math
L_{\rm CECS}=E_\alpha(t)
 -\log\frac{Z_\alpha(t)}{\sum_{u\in\mathcal T}Z_\alpha(u)},\qquad
S(y)=S_0(y)+\frac{\beta}{2}\sum_v[E_{\alpha,v}(y)-E_{{\rm uniform},v}(y)].
```

二者共享补全算子、支持权重及后验验证责任，分别负责训练信号和推断准则。
每题间隔大于新增分数的取值范围时，基础排序保持。该性质不能保证
准确率，完整测试仍是70%性能要求的证据。

末轮71.414286%。新方法没有超过续训对照，不声称候选推理性能提升。

## 2026参考及借鉴边界

- [Object-centric LeJEPA](https://arxiv.org/abs/2607.02404)：给定分区后进行组件级学习。这里沿用公开布局视图，不采用其对象发现或SIGReg表述。
- [SHINE](https://arxiv.org/abs/2602.06358)：上下文指导可执行低秩适配。这里推断已有算子的分布，不直接生成LoRA。
- [When Does LeJEPA Learn a World Model?](https://arxiv.org/abs/2605.26379)：明确可识别性需要的假设。这里仅有能量计算性质，不借其定理宣称RAVEN规则可识别。

这是单种数据集、单个种子的机制原型。补全信号已有对照证据，候选排序
的收益尚未被验证。应把这两项写成明确的方法设计与有边界的实验发现，
不能声称两项都显著提高RAVEN准确率或已经达到顶会创新标准。
