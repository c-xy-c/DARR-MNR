# Toward VNB-MNR: A Visual-Number Binding Dataset for Arithmetic Visual Reasoning

Date: 2026-06-15

This note uses the Yangshi-style research pipeline to analyze the current MNR dataset and turn the weakness into a new dataset proposal. The target is not to criticize MNR as a released benchmark, but to identify the next benchmark object that makes visual arithmetic reasoning more diagnostic about shortcuts.

## 1. Executive Summary

Current MNR successfully moves beyond Machine Number Sense by changing the task from missing-number generation to answer selection under a shared arithmetic expression. However, its visual and numerical components are not tightly coupled inside each question. In the released generator, each problem first draws one visual layout, then deep-copies that layout into all context panels, correct candidates, and wrong candidates. The candidate set is mainly produced by changing numbers or arithmetic operators while preserving the same visual layout. This means vision often acts as an address system for reading numbers from fixed positions, rather than as a semantic variable that changes the arithmetic relation.

The proposed new dataset, tentatively named **VNB-MNR** for **Visual-Number Binding Machine Number Reasoning**, makes the binding between visual roles and numeric operands the central variable. In VNB-MNR, the same number multiset can be correct or incorrect depending on whether the visual structure binds each number to the right operand role. The dataset should therefore include counterfactual candidates that preserve the number set and even preserve superficial arithmetic plausibility, but break the visual-number binding.

The Yangshi-style mechanism is:

```text
 field momentum: visual mathematical reasoning benchmarks are becoming stronger and more multimodal
 unredeemed promise: models should reason over diagrams, numbers, and abstract structure jointly
 proxy A: fixed spatial layout plus arithmetic expression match
 construct B: visual structure causally determines numeric roles and arithmetic semantics
 regime R: same numbers, same local appearance, different visual binding
 mechanism H: visual-number binding collapse
 artifact O: a counterfactual visual-number binding dataset with binding-aware metadata and metrics
```

## 2. Source And Evidence Base

### 2.1 Local Evidence From DARR-MNR

The current repository contains the MNR generator but not released full dataset files. The generator and paper are enough to diagnose the dataset design.

| Evidence | Observation | Research implication |
| --- | --- | --- |
| `mnr_dataset/Drawing.py` lines 88-110 | A visual layout is drawn once, then copied into all context and answer images. | Within a question, visual layout is mostly constant across candidates. |
| `mnr_dataset/Drawing.py` lines 112-127 | Different panels are generated by writing different integer lists onto copied visual layouts. | Candidate differences mostly live in numbers, not visual structure. |
| `mnr_dataset/main.py` lines 71-93 | The correct candidate is one generated panel; seven wrong panels are randomly selected and shuffled. | The answer set is not explicitly balanced by counterfactual visual-binding types. |
| `mnr_dataset/main.py` lines 147-151 | Saved `.npz` fields are only `context_images`, `answer_set_images`, and `correct_answer_image_index`. | Downstream analysis cannot audit expression, visual role, negative type, or shortcut type without regenerating metadata. |
| `mnr_dataset/Num_Arrange.py` lines 352-360 and 1295-1319 | Analytical negatives use `MutFalse`, which mutates one or two displayed numbers while keeping the operator list unchanged. | Some negatives can be solved as local numerical anomaly detection. |
| Small local probe | Generating one sample per configuration produced 145 files, all with image arrays and answer index only. | Dataset metadata is insufficient for mechanism-level diagnostics. |

### 2.2 Evidence From The DARR Paper

The DARR paper positions MNR as an arithmetic visual reasoning benchmark over number sense and spatial layouts. It states that each question contains three context images and eight candidates, where one candidate follows the same arithmetic expression as the contexts. It also states that the three context images are generated from a shared problem type, spatial layout, and algebra while differing in specific numbers. Wrong candidates are generated by modifying the arithmetic expression, and shorter analytic cases may mutate numbers because only changing operators can leak easy clues.

This design is reasonable for moving beyond missing-number search. The gap is that the paper's high-level claim is about reasoning over number sense and spatial layout, while the construction mostly holds spatial layout fixed inside each multiple-choice question. Thus the benchmark tests whether the model can use layout to choose an ordering or grouping template, but it does not strongly test whether changes in layout causally change arithmetic semantics.

### 2.3 Recent Literature Signals

Recent visual mathematical reasoning work has moved toward richer multimodal tasks, stronger contamination controls, and process-level diagnosis:

| Work | Signal For This Proposal |
| --- | --- |
| DARR / MNR, AAAI 2025 | Clean abstract arithmetic visual reasoning remains valuable, but current MNR can under-couple visual structure and numeric semantics. |
| Machine Number Sense, AAAI 2020 | Earlier visual arithmetic benchmarks focused on discovering expressions or missing numbers, motivating MNR's answer-selection formulation. |
| MathVista, ICLR 2024 | Visual math benchmarks now cover broader math contexts and multimodal reasoning, but often include natural images, text, and diagrams rather than controlled abstract counterfactuals. |
| MathVerse, ECCV 2024 | Recent work explicitly asks whether multimodal models truly use diagrams in visual math problems, aligning with this proposal's shortcut concern. |
| MATH-Vision, NeurIPS 2024 Datasets and Benchmarks | High-difficulty visual math evaluation is becoming important for frontier multimodal models. |
| DynaMath, 2024 | Dynamic or programmatic visual math generation is useful for reducing memorization and testing robustness. |
| VC-Bench, 2025 | Recent benchmarks explicitly target visual dependency in multimodal mathematical reasoning, reinforcing the need to prevent text-only or number-only shortcuts. |
| VisuLogic, 2025 | Vision-centric reasoning benchmarks increasingly diagnose whether models rely on non-visual shortcuts. |
| VisioMath, 2025 | Image-option math benchmarks emphasize fine-grained distinctions between visually similar answer choices. |

The opening is therefore clear: large multimodal benchmarks test broad capability, while MNR tests clean abstract arithmetic. VNB-MNR can occupy the missing middle: a controllable, programmatic benchmark where the visual structure is not merely a carrier for numbers but the variable that determines the arithmetic role of each number.

## 3. Yangshi Proxy Split

| Item | Definition For Current MNR |
| --- | --- |
| Proxy A | A candidate is correct if numbers in a fixed visual layout satisfy the same arithmetic expression as context panels. |
| Construct B | A model should infer how visual structure binds numbers to operand roles, groups, and operations, then reason over the resulting expression. |
| Failure regime R | Same number multiset and similar local appearance, but different visual binding changes which expression is semantically valid. |
| Mechanism H | **Visual-number binding collapse**: the model can treat visual layout as an address map instead of a semantic constraint. |
| Probe P | Build counterfactual pairs where number-only evidence is preserved but visual binding is swapped; measure whether models change answers correctly. |
| Minimal artifact O | A dataset generator, metadata schema, and evaluation protocol that explicitly vary visual-number binding under controlled arithmetic constraints. |

Diagnostic thesis:

```text
If visual-number binding collapse is real, then under counterfactual layouts that preserve numbers but alter visual roles, models trained or evaluated on current MNR-style data should over-rely on fixed numeric addresses and fail to track binding-valid answers.
```

## 4. What Is Missing In Current MNR

### 4.1 The Visual Variable Is Mostly Static Within A Question

MNR uses rich layouts across the dataset: combination, composition, partition; different shapes; holistic and analytic interpretation. Across configurations, this is useful. Within one question, however, all candidate panels share the same drawn layout. That creates a regime where visual perception is needed to locate numbers and perhaps infer an ordering template, but not to discriminate candidate validity through visual semantics.

This matters because multiple-choice reasoning is shaped by the candidate set. If the answer candidates differ mostly by numbers, then the dataset encourages numeric-expression discrimination. A model can improve by learning coordinate-specific number extraction plus expression matching, without learning that a different visual relation should change the expression.

### 4.2 The Negative Candidates Are Not Mechanism-Balanced

Wrong candidates are generated by operator, parenthesis, or number mutations. These are useful negatives for expression matching, but they are weak negatives for visual binding. A stronger benchmark should include wrong candidates that:

- keep exactly the same number multiset,
- preserve low-level visual complexity,
- preserve a plausible arithmetic expression under a coordinate shortcut,
- break only the mapping between visual role and operand role.

These negatives would force a solver to distinguish "the number at coordinate x" from "the number bound to role r by the visual structure."

### 4.3 Metadata Is Too Thin For Scientific Diagnosis

The current `.npz` files save images and the answer index. That is enough for classification training, but not enough for a benchmark that wants to diagnose reasoning. For a new dataset, the saved sample should include:

- problem type,
- visual grammar instance,
- object identities,
- numeric values,
- role-to-number binding,
- expression tree,
- correct candidate derivation,
- negative candidate type,
- counterfactual pair id,
- shortcut that each negative is meant to defeat.

Without this metadata, it is difficult to build mechanism metrics, stratified leaderboards, or error taxonomies.

## 5. Proposed Dataset: VNB-MNR

### 5.1 One-Sentence Thesis

Although recent visual mathematical reasoning benchmarks suggest progress toward diagram-aware reasoning, current abstract arithmetic benchmarks can treat fixed spatial layout as a proxy for visual-number understanding; VNB-MNR exposes visual-number binding collapse through counterfactual samples where visual structure, not the number multiset alone, determines arithmetic validity.

### 5.2 Core Task

Given three context panels and eight candidate panels, select the candidate that follows the same **visual-number binding rule** and the same **arithmetic expression schema** as the context panels.

The key change from MNR is that candidate panels are not only numerical variants. Some candidates preserve the same numbers but alter the visual binding graph. Correctness depends on whether numbers are assigned to the right semantic roles by the visual structure.

### 5.3 Formal Objects

Let each panel be generated from:

```text
G = visual scene graph
R = visual roles extracted from G
b: R -> N = binding from visual roles to displayed numbers
E = arithmetic expression over roles
y = evaluation target or rule-consistency label
```

A candidate is valid if it satisfies both:

```text
E(b_candidate(R_candidate)) = target relation
and
role schema(candidate) matches role schema(context)
```

This formulation makes the visual scene graph part of the arithmetic semantics rather than a background canvas.

### 5.4 Visual Role Families

The generator should include visual roles that are easy to render but hard to shortcut by fixed coordinates.

| Family | Example roles | Binding challenge |
| --- | --- | --- |
| Containment | outer, inner, shared overlap, excluded region | Same coordinate can change role under nesting or overlap. |
| Partition | segment id, adjacent segment, opposite segment, same-color region | Operand role depends on region membership. |
| Symmetry | mirror pair, axis-side pair, rotational orbit | Grouping depends on symmetry, not reading order. |
| Path / topology | start, end, branch, cycle node, articulation point | Expression follows graph relation rather than x-y order. |
| Set relation | union, intersection, difference, complement | Numbers belong to visual set operations. |
| Relative geometry | nearest, farthest, clockwise successor, inside-angle | Role depends on spatial relation among objects. |

### 5.5 Arithmetic Schemas

Arithmetic should remain simple enough that failure is attributable to binding, not raw calculation difficulty. Good schemas:

```text
r1 + r2 - r3 = c
r_outer - r_inner = c
(r_left + r_right) / r_center = c
r_intersection + r_difference = r_union
sum(group A) - sum(group B) = c
product(pair 1) = product(pair 2)
```

The first version should avoid long expressions. The goal is not to create the hardest calculator; the goal is to make visual binding necessary.

## 6. Counterfactual Negative Types

The dataset should define negatives by what shortcut they falsify.

| Negative type | What is preserved | What is broken | Shortcut falsified |
| --- | --- | --- | --- |
| Number-only false positive | Same number multiset | Role-number binding | Bag-of-numbers reasoning |
| Coordinate false positive | Same coordinate-wise numbers | Visual role assignment | Fixed-address reading |
| Expression false positive | Candidate satisfies expression under wrong role map | Binding schema | Expression-only search |
| Layout false positive | Same layout class | Fine-grained relation, e.g. adjacency or containment | Coarse visual classification |
| Perception false positive | Same digits, same roles | Small visual relation edit changes grouping | OCR-only reasoning |
| Easy arithmetic negative | Different numbers violate expression | None | Maintains compatibility with standard MNR evaluation |

The important design choice is that each question should include at least one binding counterfactual. Otherwise the benchmark can still be solved with number-centric shortcuts.

## 7. Dataset Splits And Protocols

| Protocol | Split rule | What it tests |
| --- | --- | --- |
| P1: Standard IID | Random split within configurations | Basic learnability and comparability. |
| P2: Binding-OOD | Hold out visual role families, e.g. train on containment and symmetry, test on topology | Whether models learn binding principles beyond seen layouts. |
| P3: Expression-OOD | Hold out arithmetic schemas | Whether visual binding generalizes beyond memorized expressions. |
| P4: Counterfactual stress | Test only paired samples where number-only and binding-aware labels diverge | Whether models actually use visual binding. |
| P5: Shortcut challenge | Candidate sets are adversarially balanced to make number-only solvers fail | Robustness against fixed-address and bag-of-number shortcuts. |

P4 should be the signature leaderboard because it directly measures the proposed mechanism.

## 8. Metrics

| Metric | Definition | Mechanism role |
| --- | --- | --- |
| Accuracy | Standard 8-way candidate accuracy | Main benchmark score. |
| Binding Counterfactual Accuracy (BCA) | Accuracy on samples where number-only evidence conflicts with binding evidence | Main mechanism metric. |
| Counterfactual Consistency (CC) | Whether predictions flip correctly across paired role-swap samples | Measures sensitivity to binding interventions. |
| Number-Only Gap (NOG) | Full-model accuracy minus number-only baseline accuracy on binding counterfactuals | Quantifies how much vision contributes beyond numbers. |
| Layout Sensitivity Index (LSI) | Change in correct-candidate probability under visual role intervention with numbers fixed | Detects fixed-address shortcuts. |
| Shortcut Reliance Rate (SRR) | Fraction of errors matching a known shortcut baseline | Turns failure into an error taxonomy. |

These metrics should be computable from metadata before training any new architecture.

## 9. Baseline Panel

| Baseline | Role | What it can falsify |
| --- | --- | --- |
| Random | sanity baseline | Dataset labeling or answer imbalance issues. |
| Number-only solver | naive proxy baseline | Whether numbers alone solve the task. |
| Coordinate-expression solver | stronger shortcut baseline | Whether fixed visual addresses solve the task. |
| Metadata oracle | upper bound | Whether the generated rules are internally consistent. |
| DARR | strong MNR-era model | Whether current arithmetic regression reasoning handles binding counterfactuals. |
| PredRNet / SCAR / MRNet | abstract visual reasoning baselines | Whether generic visual reasoners handle binding better than arithmetic-specific models. |
| VLM prompt baseline | modern multimodal baseline | Whether frontier multimodal models truly use the diagram under controlled counterfactuals. |

The minimum credible paper should include the first five. VLM baselines are useful but not required for the first mechanism probe.

## 10. Minimal Generator Design

### 10.1 Sample Pipeline

```text
1. Sample a visual grammar family F.
2. Sample a scene graph G with object ids and roles R.
3. Sample a role-level expression E.
4. Sample number values N satisfying E under binding b.
5. Render three context panels with different values but same binding schema.
6. Render one correct candidate.
7. Render seven negatives from controlled counterfactual operators.
8. Save images plus full metadata.
```

### 10.2 Metadata Schema

```json
{
  "sample_id": "...",
  "family": "containment",
  "split_protocol_tags": ["standard", "binding_counterfactual"],
  "context": [
    {
      "scene_graph": {},
      "roles": ["outer", "inner", "intersection"],
      "numbers": {"outer": 12, "inner": 4, "intersection": 3},
      "expression_tree": ["-", "outer", ["+", "inner", "intersection"]]
    }
  ],
  "candidates": [
    {
      "is_correct": true,
      "negative_type": null,
      "shortcut_target": null,
      "binding_map": {},
      "expression_value": 5
    },
    {
      "is_correct": false,
      "negative_type": "coordinate_false_positive",
      "shortcut_target": "fixed_address",
      "binding_map": {},
      "expression_value": 5
    }
  ]
}
```

The exact JSON can be simplified later, but the dataset should not release image-only samples if the paper claim is diagnostic.

## 12. Minimum Experiment Package

### 12.1 One-Week Probe

Build a tiny containment-only generator with 1,000-5,000 samples:

- roles: outer, inner, overlap, outside,
- expressions: three simple schemas,
- negatives: number-only false positive, coordinate false positive, easy arithmetic negative,

```text

2. **VNB-MNR: Diagnosing Visual-Number Binding in Arithmetic Visual Reasoning**

VNB-MNR: Diagnosing Visual-Number Binding in Arithmetic Visual Reasoning
```

### Story Spine

1. Progress: visual mathematical reasoning benchmarks and MNR-style abstract arithmetic tasks show growing interest in multimodal number reasoning.
2. Promise: a model that solves these tasks should jointly understand numbers, diagrams, and abstract visual structure.
3. Failure: current abstract arithmetic datasets can hold visual structure fixed while varying numbers, making vision an address map.
4. Proxy split: expression matching in a fixed layout is treated as visual-number reasoning.
5. Mechanism: this produces visual-number binding collapse.
6. Lens: counterfactual role-binding interventions make the collapse measurable.
7. Artifact: VNB-MNR provides a generator, metadata, negative taxonomy, and binding-aware metrics.
8. Evidence: shortcut baselines, strong AVR baselines, and stress tests verify that binding counterfactuals expose a gap not visible in standard accuracy.

## 15. Falsifiers

The proposal should be weakened or parked if:

- a number-only or fixed-coordinate solver performs poorly even on current MNR-like negatives, meaning the shortcut is not strong;
- DARR already handles binding counterfactuals well without modification;
- humans find the counterfactual task ambiguous;
- generated labels are unstable because multiple role bindings are valid;
- binding metrics do not correlate with model errors;
- VNB-MNR becomes a visual perception benchmark rather than arithmetic binding benchmark.

## 16. Design Rules For The New Dataset

1. Every sample must include at least one binding counterfactual negative.
2. At least one negative should preserve the exact number multiset.
3. At least one negative should be correct under a known shortcut but wrong under visual binding.
4. The generator must save metadata sufficient to recompute labels.
5. Arithmetic difficulty should be capped in v1 so failures are attributable to binding.
6. The first paper should report shortcut baselines before reporting large model baselines.
7. Claims should use "diagnose", "expose", and "measure" before using stronger claims like "solve" or "human-like".
